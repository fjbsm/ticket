# 票根工坊（Ticket Studio）

一个纯本地运行的票根生成器：上传图片，套上票根样式，一键导出高清 PNG。

## 功能

- 上传图片（拖拽或点击），自动裁切到左侧主券区域
- 5 种票纸主题：经典白、海盐绿、暗夜金、莓果粉、雾蓝
- 5 种票根比例：1:1、4:3、3:2、16:9、2:1
- 编辑演出 / 活动名称、副标题、日期、时间、地点、座位、票价、票号
- 复古印章开关、基于票号的确定性条码
- 实时预览，多档位高清 PNG 导出（800 / 1200 / 1600 / 2400 / 3200 px）
- 全程在浏览器本地处理，图片不会上传到任何服务器

## 使用

直接用浏览器打开 [index.html](index.html) 即可，无需安装任何依赖。

## 技术说明

- 单文件 HTML，使用 Canvas 渲染票根
- 预览与导出共用同一渲染函数，保证效果一致
- 依赖网络加载的仅有一份 Google Fonts 字体（思源宋体 / 思源黑体），离线时自动回退到系统字体
